# Оценка американского put-опциона методом Монте-Карло

## О проекте
Реализация алгоритма Лонгстаффа-Шварца (Least Squares Monte Carlo, LSM) для оценки стоимости американского put-опциона.
Задача: сравнить метод Монте-Карло с классической биномиальной моделью Кокса-Росса-Рубинштейна (CRR) и исследовать сходимость алгоритма.

## Модель
- Геометрическое броуновское движение (GBM) в риск-нейтральной мере
- Параметры: S₀ = 100, σ = 0.3, r = 0.05, T = 1 год, K = 105
- Американский put-опцион с возможностью досрочного исполнения

## Использованные методы и технологии
- **Язык:** Python
- **Библиотеки:** numpy, scipy, scikit-learn, matplotlib
- **Методы:**
  - Алгоритм Лонгстаффа-Шварца (обратная индукция + регрессия на полиномах)
  - Биномиальная модель CRR для бенчмарка
  - Исследование сходимости по числу траекторий M (100 → 20 000)
  - Исследование влияния числа временных шагов N (10 → 200)
  - Анализ влияния степени полинома (1 → 5)
  - Сравнение точности с биномиальной моделью

## Что сделано
- Реализован алгоритм LSM с нуля
- Проведено исследование сходимости: стандартная ошибка убывает как O(1/√M)
- Сравнение с биномиальной моделью для N = 10…100
- Проанализировано влияние базисных функций на точность и долю досрочных исполнений
- Построены графики сходимости, распределения моментов исполнения и аппроксимации функции выплат
